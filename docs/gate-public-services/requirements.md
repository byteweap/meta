# Gate 服务可用性与转发错误

本阶段延续客户端请求链路重构，基线为 `5952969`。Gate 的发现和错误回包行为按 Level 2 记录。

- 注册中心按目标服务名返回可用实例后，Gate 即可转发。业务服务独立上下线，Gate 无需变更配置。命令与版本由 Mesh 路由。
- 首次查询没有匹配实例时返回 404，并且不为该服务创建常驻监听。实例发生变更时更新本地快照，全部下线后释放监听，后续请求可重新发现。
- 已绑定玩家只向快照中的原实例转发。绑定失效且服务仍有其他实例时返回 503。
- 定位、发现或发布报错时，Gate 在原连接尝试回复一次 503。回复携带原 seq、cmd、version 和 Gate 服务名及发送时间。成功转发的原始帧和会话身份保持一致。
