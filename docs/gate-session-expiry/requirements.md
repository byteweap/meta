# Gate 会话归属异常失效

基线为 `66d7780`。Gate 异常退出时，连接的断开回调可能没有机会执行。在线归属需要在最后一次成功写入或续期后的有限时间内失效，使后续 UID 推送能识别离线。按 Level 2 记录定位器契约和跨模块行为。

- 每次 Gate 启动生成独立运行 ID，建立一份 60 秒租约，每 15 秒续期一次。用户会话引用该运行 ID。普通断开仍立即尝试释放。
- 会话查询检查绑定所引用的租约，租约不存在时返回空节点和最后一个会话 ID。普通位置查询读取绑定数据，沿用原来的单次 Redis 命令。
- Gate 续期只延长已有租约。存储明确拒绝续期，或最后一次确认的有效期耗尽时，Gate 启动停止流程。暂时的存储错误在剩余有效期内重试。复用应用 ID 启动将使用新的运行 ID，旧归属保持离线。
- 并发认领时，写入前比较已读取的会话 ID。如果另一连接已抢先更新归属，必须重新检查运行租约才能再次尝试写入。
- 释放仍原子比较节点和会话 ID，只有实际释放才发送离线事件。Gate 存活期间单次释放失败仍可能留下该连接的旧归属。
- 验证覆盖多个会话共用一次续期、到期、复用应用 ID、旧会话释放、普通业务绑定、存储故障及 `Push` 的离线判定。使用单个 Gate 或 Mesh 的测试。
