# Gate 无状态转发

以 `d3ef72d` 为基线。按 Level 2 记录业务服务声明和 Gate 转发契约。

- 业务服务通过注册元数据 `stateless=true` 声明无状态。新增服务或发现快照更新时，Gate 根据最新可用实例决定转发方式。
- 快照内所有可投递实例均明确声明无状态时，Gate 直接从本地快照选点，一次转发不调用玩家定位器。
- 无状态选点继续使用 UID 作为选择器的 key。注册适配器必须保存业务声明及其他实例元数据。
- 快照缺少声明、声明值不匹配或实例声明不一致时，按玩家绑定优先转发。已绑定实例下线且服务仍有可用实例时返回 503。
- 服务可用性、客户端错误回包、会话标记和消息协议仍遵守当前约定。房间归属由业务服务管理。
- 验证声明组合、同实例元数据变化、服务动态上下线、选点失败和定位调用次数。沿用单节点验证范围。
