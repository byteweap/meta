# 全仓库 Go 测试覆盖率

补充覆盖率审计发现缺口的测试。基线为 `188a374`，21 个模块的默认测试和 3 个模块的集成套件通过。58 个具有可执行语句的包中，47 个未达到覆盖率门槛。

| 验收项 | 要求 |
| --- | --- |
| AC-01 | 每个具有可执行语句的 Go 包，其语句覆盖率严格大于 95%。用覆盖率文件中的实际语句数核对，避免舍入影响判定。 |
| AC-02 | 测试对正常行为和重要的边界、错误或取消场景作断言。沿用现有覆盖统计范围和对外契约。 |
| AC-03 | 复跑所有 Go 模块的默认测试及现有集成套件，运行相关 Go lint、跨模块构建和差异检查。 |

实施和逐项验证见 [进度记录](progress.md)。
