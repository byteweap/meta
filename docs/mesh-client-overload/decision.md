# 客户端过载拒绝

复用串行队列和既有客户端响应链路。选项启用时，订阅回调先尝试非阻塞入队，仅在满队列时同步尝试一次拒绝回包。这个路径使用限时上下文，停服时随准入上下文一并取消。Broker 适配器决定在途 I/O 对取消的响应时机。

同步回包省去第二条队列和每次拒绝的 goroutine，并保留可关联的过载反馈。释放准入读锁后再尝试发布。关闭准入后，Mesh 在完成清理前等待正在尝试的拒绝回包退出。`Stop(ctx)` 仍受调用方期限约束。

拒绝回包名额为每个 Mesh 一个，使用同一个信号量等待回包退出。名额用尽时，后续拒绝只计数。回包从 Protobuf 线格式取出请求头并校验外层帧，跳过载荷内容。重复出现的请求头按 Protobuf 规则合并。
