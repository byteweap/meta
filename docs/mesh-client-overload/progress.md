# Mesh 客户端请求过载保护实施记录

[验收范围](requirements.md) · [设计决策](decision.md)

- Gate 无状态路由 `46d6fd0` 已快进合入本地 `dev`。客户端过载保护分支从该提交创建。
- [准入与排空](../../server/mesh/mesh.go)在选项启用时为客户端业务消息尝试非阻塞入队，事件和 RPC 继续使用既有准入。拒绝回包在释放准入锁后发布，清理会等待已经开始的回包尝试退出。
- [拒绝响应](../../server/mesh/client_overload.go)复用客户端响应编码和 Broker 会话标记。检查 UID、原会话 ID、回复地址和外层协议头，并在回包上下文到期或准入停止时取消发布。
- 自审核对了队列关闭与在途回包登记的先后顺序。登记发生在准入读锁内，取消准入并关闭队列后才等待，回包调用在锁外。
- [回归测试](../../server/mesh/client_overload_test.go)覆盖满队列拒绝、原会话和 `seq=0`、缺少会话、无效帧、已接收请求的顺序、关闭选项以及 RPC 和会话事件准入、回包超时和排空等待。专项竞态验证通过二十轮。
- 单个 Mesh 连接实际 NATS，先收到满队列请求的 503，再排空两个已入队请求并按序回包。该验证通过五轮竞态检查。根模块测试、Gate 和 Mesh 三轮竞态检查、NATS 模块竞态检查及 21 个模块构建通过。按约定跳过两个单进程多节点测试，变更范围 lint 为零问题。

## 复审修复

- 复审用 32 路并发投递复现了 32 个在途拒绝回包。现在每个 Mesh 最多持有一个回包名额。回归测试验证只有一路发起发布，其余 31 路返回且各自计入 `QueueFull`，名额会在回包结束后复用。
- 拒绝路径原本复制整个业务载荷。现在扫描完整外层帧，只解码请求头。对照完整 Protobuf 解码验证重复请求头、显式零值、未知字段、非法字段号、截断载荷及非法 UTF-8。
- 以上回归和原始并发复现通过二十轮竞态检查。单 Mesh NATS 回环复验通过五轮，Gate 和 Mesh 竞态检查通过三轮。根模块测试、变更范围 lint 及 21 个模块构建通过。按约定跳过两项单进程多节点用例。

## 本地性能

Apple M1、Go 1.27.1，基线和当前版本交替运行五轮，每轮单核 400 毫秒。测试一次只发送一个带 128 字节 Protobuf 业务载荷的客户端请求，测量从 Broker 订阅回调入队到内存 Broker 收到回复的耗时。队列有空位，观测关闭。

| 配置 | 耗时中位数 | 每请求分配 |
| --- | ---: | ---: |
| 基线 | 1311 ns | 1516 B，21 次 |
| 当前默认关闭 | 1345 ns | 1516 B，21 次 |
| 当前启用保护 | 1274 ns | 1516 B，21 次 |
