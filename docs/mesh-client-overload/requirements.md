# Mesh 客户端请求过载保护

以 `46d6fd0` 为基线。按 Level 2 记录可选准入行为和回包约定。

- Mesh 可显式启用客户端请求的满队列快速拒绝，默认沿用阻塞入队行为。
- 队列满时记录一次 `QueueFull`。可解析的上行帧若携带原会话身份和回复地址，尝试一次 503，保留原 `seq/cmd/version`。缺少回包所需信息时只计拒绝。
- 会话事件和 RPC 沿用各自的准入规则。成功入队的请求按原顺序执行和排空。
- 拒绝回包使用 100 毫秒的上下文。开始停服时取消尚在执行的拒绝回包，Mesh 清理等待已开始的尝试结束。
- 使用单个 Mesh 和受控 Broker 验证默认入队、满队列、正常回复、会话身份、发送超时及排空。
