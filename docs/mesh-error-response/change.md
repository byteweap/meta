## 问题与目标

[Context.ErrResp](../../server/mesh/context.go) 使用 `lang.If(len(args) > 0, args[0], ...)` 选择提示。Go 在调用函数前先求值全部参数，无参数时读取 args[0] 越界，导致错误响应无法发送。

目标是使用普通条件判断：先设置默认提示 `mesh internal error`，仅有参数时读取首项。显式空字符串仍为空，多个参数仍使用首项；移除无用导入。不增加兼容分支，也不修改通用 lang.If。
