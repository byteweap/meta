# Mesh 入站 RPC 并发

在 `8b7e38d` 上为等待 I/O 的服务间 RPC 提供有界并发。默认沿用同一消息循环的处理顺序。

- 业务显式指定 worker 数和等待队列容量。多个 RPC 可以同时执行，客户端路由与会话事件继续串行处理。业务负责同步与 RPC 共享的可变状态。
- 并发数和排队数量分别受限。Mesh 就绪时可以立即使用已配置的执行名额，队列容量为零也适用。队列满立即回复 503，已入队请求在出队时过期则回复 504，两者均跳过业务处理。
- 停止时取消执行上下文，处理已接纳的请求，每个请求只尝试回复一次。关闭 RPC 接收前送达的新请求尝试回复 503，清理队列时继续校验请求截止时间。`Stop(ctx)` 的等待受调用方期限约束。
- 用单个 Mesh、受控 Broker 和可阻塞的 handler 验证顺序、隔离、过载、期限与停止。分别测量默认分发和并发分发的成本。
