# 服务间 RPC 截止时间实施记录

[验收范围](requirements.md)对应提交基线 `5ef28cd`。[调用示例](../../README.md#服务间-rpc)给出类型化 handler 和调用方的用法。

## 执行与传输约定

- [Mesh.Request](../../server/mesh/mesh.go) 接受调用方的标准上下文，运行中的 Mesh 同时约束其本地等待。发送端将有效截止时间写入 `deadline_unix_ms`。同一绝对时间能计入 Broker 传输和 Mesh 队列等待，嵌套调用沿用剩余时间。取整可能使远端提前不足 1 ms 到期，机器间的时钟偏差也会影响远端判断。
- 接收端在出队后检查请求头。格式错误回复 400，到期回复 504。每个带期限的请求使用可取消的标准上下文，业务结束时释放它。无期限请求直接使用 Mesh 运行上下文。handler 需要将 context 传给阻塞操作，处理器主动返回后 Mesh 才能继续分发下一条消息。
- [WrapRPC 和 RPCRouteX](../../server/mesh/handler_rpc.go) 继续接收现有业务函数签名，通过 [RPCContext.Context()](../../server/mesh/context_rpc.go) 提取执行上下文。原始 `RPCMessageHandler` 新增首个 `context.Context` 参数。取消通知在本进程内生效，跨进程只传递截止时间。
- 最后一次回包保留 Mesh 上下文中的值，发送期限独立于业务和 Mesh 的截止时间。串行消息循环复用 1 秒的发送期限，剩余不足 500 毫秒时更新，退出循环后释放定时器。这样停服期间可以发送已处理的结果，正常流量也能分摊定时器成本。

## 验收证据

| 行为 | 验证 |
| --- | --- |
| 调用方主动取消、到期或 Mesh 停止时结束等待 | [请求回归](../../server/mesh/rpc_deadline_test.go)覆盖调用前后取消、Mesh 较早的截止时间和停止边界 |
| 启动前缺少 Broker | 同文件验证返回 `ErrBrokerRequired`、空响应和零状态码 |
| 停服回包与发送期限 | 同文件验证处理时停服、运行期限到期、发送时停服，以及发送期限的复用、更新与到期。用先前复现问题的单 Mesh 与真实 NATS 临时用例执行三轮竞态检查，调用方分别收到 503、504 |
| 排队计时和执行中到期 | 同文件通过虚拟时钟控制真实 Mesh 消息队列。已过期的排队请求跳过业务，执行中的 handler 收到 `Done()`，返回的迟到结果只触发一次 504 回复 |
| 嵌套请求和正常回包 | 原始、类型化和反射入口分别验证下游收到相同截止时间、正确的数据及状态码，且调用完成后请求定时器被释放 |
| 实际传输 | [NATS 请求回复测试](../../contrib/broker/nats/broker_test.go)核对服务端收到的完整 Broker 请求头。回包测试通过通道传递结果，消除测试协程间的竞态 |

根模块及 game 示例测试通过，Mesh 和 NATS 模块各执行三轮竞态测试通过。`make check` 构建全部 21 个模块成功。根模块测试按约定跳过既有的两项同进程多节点用例。

自查复现的停服回包丢失和启动前缺少 Broker 导致的 panic 均已修复。修复后 Mesh 包 lint 通过。此前根模块、NATS 模块增量 lint 均通过，全量 lint 仍有既有诊断，根模块默认显示 13 项，NATS 模块显示 2 项。

## 接收端基准

[BenchmarkRPCDispatch](../../server/mesh/rpc_deadline_bench_test.go)使用预编码的 Protobuf BytesValue，业务载荷 128 字节。每次从 Mesh 收到 Broker 消息开始，覆盖路由、解码、类型化 handler 和内存 Broker 接收回复。发送端、排队等待与网络 I/O 均不在计时范围。Apple M1，Go 1.27.1，`-cpu=1 -benchmem -count=5`，耗时取中位数。

| 版本与输入 | ns/op | B/op | allocs/op |
| --- | ---: | ---: | ---: |
| 基线，无截止时间 | 309.0 | 256 | 7 |
| 修复停服回包前，无截止时间 | 336.8 | 256 | 7 |
| 修复停服回包前，有截止时间 | 836.7 | 528 | 11 |
| 修复后，无截止时间 | 370.3 | 256 | 7 |
| 修复后，有截止时间 | 882.7 | 528 | 11 |
