# Mesh 服务间 RPC 的请求截止时间

本次在 `5ef28cd` 上补齐服务间 RPC 的等待和执行期限。公共调用签名及 Broker 请求头按 Level 2 记录。

- 调用方通过 `Mesh.Request(ctx, ...)` 传递本次请求的取消信号和可选截止时间。调用方结束等待以及 Mesh 停止时，释放在途调用资源。
- 截止时间覆盖传输、排队和执行。到达接收端时已经过期的请求跳过业务，执行中的 handler 能观察到上下文到期，嵌套 RPC 沿用剩余时间。
- 通过同一个回包出口处理超时、成功和业务失败。无截止时间的请求沿用 Mesh 生命周期执行业务。已处理请求的回包有独立的发送期限，Mesh 停止或到期时也只尝试发送一次。
- 支持在 Mesh 启动前发送 RPC。未配置 Broker 时返回框架已有的 `ErrBrokerRequired`。
- 使用受控 Broker 验证发送、排队、执行和回复，单独记录有无截止时间的成功路径分配。
