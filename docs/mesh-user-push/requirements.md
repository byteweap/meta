# Mesh 按 UID 主动推送

基线为 `010fd43`。业务在 Mesh 就绪后用 UID、命令、版本和可选 Protobuf 消息发送推送。按 Level 2 记录新增的公共 API 与调用约定。

- 以 UID 和 Gate 逻辑服务名读取一次当前会话。默认 Gate 服务名为 `gate`，部署使用其他名称时在 Mesh 初始化时指定。会话不存在或已经释放时返回可识别的离线错误，跳过发布。
- 在线时向查到的 Gate 实例发布一次。外层为 `MSG_TYPE_PUSH`，序号为零，来源是 Mesh 服务，Broker 头标记 `delivery=push` 并省略会话 ID。定位、编码和发布错误直接返回。
- 成功表示 Broker 适配器已接受发布。重连期间按查询得到的节点投递一次，下一次推送重新定位。用户可能在定位后离线或迁往其他 Gate。
- 定位和发布共享调用期限。开始定位前、定位完成后及发布前均检查有效期限。已进入发布阶段的调用返回 Broker 的结果。
- 从就绪、调用方取消、Mesh 停止、定位和发布边界验证结果。使用单 Mesh、受控定位器和 Broker 检查投递次数、目标地址以及可被客户端解码的帧。
