# 请求链路观测

以合并会话租约与 Mesh 排空后的 `fbe1e56` 为开发基线。按 Level 2 记录可选组件的公开契约与验证。

- Gate 计时覆盖服务发现、定位和选点，失败仍按已有的协议响应。
- Mesh 计时覆盖本地队列、业务 handler 和向 Broker 提交回包，适用于客户端请求和入站 RPC。RPC 串行和并发模式都要覆盖。
- 分别报告目标不可用、RPC 名额用尽、RPC 执行预算耗尽、停止期间拒收或丢弃。由业务返回的状态码不计入框架拒绝。
- 通过统一的组件接口注入观测回调。默认关闭，关闭时跳过观测计时和回调，逐条消息的内存分配量保持不变。
- 保留已有消息协议、路由规则和生命周期。沿用单节点验证范围。
